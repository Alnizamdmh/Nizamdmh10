1| # النظام (Nizam) - تطبيق أندرويد
2| 
3| تطبيق أندرويد رسمي متكامل تم تطويره بلغة **Kotlin** وواجهة **Jetpack Compose** وقاعدة بيانات محلية **Room**، يجمع بين:
4| 1. **مستعرض وإدارة الملفات السحابية (Google Drive Explorer)**:
5|    - استعراض المجلدات والملفات (ملفاتي، المشتركة معي، المميزة بنجمة، سلة المهملات).
6|    - مسار المجلدات التفاعلي (Breadcrumbs) وعرض الشبكة والقائمة.
7|    - عمليات إدارة الملفات الكاملة: إنشاء مجلد جديد، إنشاء مستند نصي، تعديل الاسم، النقل للمهملات، الاستعادة، [...]
8|    - محرك بحث متقدم مع فلاتر نوع الملف، والمالك، وتاريخ التعديل.
9|    - قارئ المستندات المدمج مع إحصاء الكلمات وخيارات النسخ.
10| 2. **وثيقة النظام الدستو��ي العربي الإسلامي**:
11|    - التقرير التوثيقي الكامل للأركان والمبادئ الخمسة (الحاكمية، الشورى، العدل والمساواة، عقد البيعة، الرقاب[...]
12|    - مصفوفة السلطات الثلاث (التشريعية، التنفيذية، القضائية) وقضاء المظالم.
13|    - الوثائق التاريخية المرجعية (صحيفة المدينة، خطبة حجة الوداع، عهود الخلفاء).
14|    - حماية المقاصد الشرعية الخمسة (حفظ الدين، النفس، العقل، النسل، المال).
15|    - خيارات التصدير المباشر كملف Google Doc إلى ملفاتي في Drive ونسخ Markdown.
