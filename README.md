# النظام (Nizam)

تطبيق أندرويد يجمع بين إدارة الملفات عبر Google Drive وعرض وثيقة النظام الدستوري العربي الإسلامي. تم تطوير التطبيق باستخدام **Kotlin** و**Jetpack Compose**، ويستخدم **Room** للتخزين المحلي.

## نبذة عن المشروع

يهدف المشروع إلى توفير تجربة تجمع بين أدوات إدارة الملفات ومحتوى توثيقي عن النظام الدستوري العربي الإسلامي.

## المزايا

### إدارة الملفات
- استعراض الملفات والمجلدات، بما في ذلك ملفاتي والمشاركة والملفات المميزة وسلة المهملات.
- التنقل بين المجلدات وعرض المحتوى بطريقة شبكية أو كقائمة.
- إنشاء المجلدات والمستندات، وإعادة التسمية، والنقل إلى المهملات، والاستعادة.
- البحث عن الملفات باستخدام الفلاتر.
- قراءة المستندات ونسخ محتواها.

### وثيقة النظام الدستوري
- عرض مبادئ النظام وأركانه.
- تناول السلطات التشريعية والتنفيذية والقضائية.
- الإشارة إلى الوثائق التاريخية والمقاصد الشرعية.
- نسخ المحتوى بصيغة Markdown، مع إمكانية التصدير إلى Google Docs بحسب إمكانات التطبيق.

## التقنية المستخدمة

- **Kotlin** — لغة البرمجة.
- **Jetpack Compose** — بناء واجهة التطبيق.
- **Room** — التخزين المحلي.
