# النظام (Nizam) - تطبيق أندرويد

تطبيق أندرويد تم تطويره بلغة **Kotlin** وواجهة **Jetpack Compose** وقاعدة بيانات محلية **Room**، ويجمع بين:

1. **مستعرض وإدارة الملفات السحابية (Google Drive Explorer):**
   - استعراض المجلدات والملفات، بما فيها ملفاتي والمشاركة والملفات المميزة وسلة المهملات.
   - مسار تفاعلي ل��مجلدات وعرض شبكي أو قائمة.
   - إنشاء المجلدات والمستندات، وإعادة التسمية، والنقل إلى المهملات، والاستعادة.
   - البحث عن الملفات مع فلاتر.
   - قارئ مستندات مدمج.
2. **وثيقة النظام الدستوري العربي الإسلامي:**
   - عرض مبادئ النظام وأركانه.
   - تناول السلطات التشريعية والتنفيذية والقضائية.
   - عرض وثائق تاريخية مرجعية والمقاصد الشرعية.
   - خيارات للتصدير إلى Google Docs ونسخ Markdown.
